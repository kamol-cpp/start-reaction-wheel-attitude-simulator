# START — Reaction-Wheel Attitude Simulator

**Status:** Ongoing · February 2026–present  
**Area:** Undergraduate research, electromechanical integration, controls

An experimental reaction-wheel platform for studying actuator behavior and attitude-control methods.

## Work to date

- Integrated and characterized VESC-controlled BLDC actuators using an optical tachometer.
- Developed a full-system CAD assembly and checked component mass properties.
- Machined three aluminum reaction wheels and selected actuators against speed, torque, voltage, and motor-KV requirements.
- Earlier tests measured 0.1% average error between commanded and measured ERPM; CAD checks showed less than 0.3 mm center-of-rotation/center-of-mass alignment across three axes.

Sensor integration, system identification, and control experiments are ongoing. CAD files and data will be added when available for sharing.
